Devil RemoteBT Keyboard turns an Android phone into a wireless Bluetooth HID keyboard, mouse/trackpad, numpad, and game controller.

It uses the phone's built-in Bluetooth HID profile and communicates directly with compatible devices without requiring a host-side server application.

What you get:
* Keyboard, trackpad, numpad, and gamepad functionality inherited from the upstream Bluke project.
* Native Android text input using Gboard and other system keyboards.
* Live typing mode for continuous input and Buffer mode for composing before sending.
* Messenger-style Send button with automatic clearing after submission.
* Dedicated Line Break / Shift+Enter control and direct Backspace support.
* Reliable paced HID text transmission for better compatibility across hosts.
* Mechanical keyboard sound presets, haptics, Material You support, and customizable themes.
* A dedicated Hellfire red-accented theme while retaining the existing palette options.

Devil RemoteBT Keyboard is a maintained, modified version of the open-source Bluke project by Arnav Kumar (@arnav-kr).
